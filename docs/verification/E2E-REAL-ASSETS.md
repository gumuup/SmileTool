# 真实素材端到端回归

运行 `./scripts/e2e-real-assets.sh`。素材为 `Sources/SmileTool/Resources/` 中随项目公开的五张设备产品图片，不访问用户个人图片、配置目录或实体设备。

Swift 测试将真实 PNG 解码并复制到临时数据目录，写入四种设备的配置与 NUT65 层设置，再通过 SQLite → 完整 ZIP → 校验解包 → 原子恢复验证配置、全部图片的 SHA-256、图片可解码性及旧数据保留。脚本随后构建 `dist/SmileTool.app`，逐一比对应用包内五张图片与源素材的字节内容，验证签名并确认应用进程启动。临时测试目录结束后清除；运行中的 SmileTool 会由启动脚本重新启动。

2026-09-27 本机验证：真实素材回归通过；加入有线 NUT65 可选测试后，完整 `swift test` 共 59 项，54 项常规测试通过、5 项条件测试默认跳过。启动、归档和素材保全得到验证；NUT65 板载写入和真实收音仍需相应设备现场验收。

有线 NUT65 已连接时，可选运行 `SMILETOOL_NUT65_USB_READ_TEST=1 swift test --filter nut65USBReadMatchesKeyByKey`。它只读整份板载映射，再单独回读实体 A 键位置并比对，绝不发送写入命令；默认跳过，避免普通 CI 依赖实体键盘。本机该可选测试通过，设备协议 12、5 层映射。

# 真实素材端到端回归

运行 `./scripts/e2e-real-assets.sh`。素材为 `Sources/SmileTool/Resources/` 中随项目公开的五张设备产品图片，不访问用户个人图片、配置目录或实体设备。

Swift 测试将真实 PNG 解码并复制到临时数据目录，写入四种设备的配置与 NUT65 层设置，再通过 SQLite → 完整 ZIP → 校验解包 → 原子恢复验证配置、全部图片的 SHA-256、图片可解码性及旧数据保留。脚本随后构建 `dist/SmileTool.app`，逐一比对应用包内五张图片与源素材的字节内容，验证签名并确认应用进程启动。临时测试目录结束后清除；运行中的 SmileTool 会由启动脚本重新启动。

2026-09-27 本机验证：真实素材回归通过；完整 `swift test` 共 58 项，54 通过、4 项实体音频条件测试跳过。启动、归档和素材保全得到验证；实体按键、NUT65 板载写入和真实收音仍需相应设备现场验收。
